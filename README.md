## 🌟 단지 핵심 특성 (단일 59㎡ 평형 혁신)
* **기존 평형**: 1996년 준공 총 709세대 **전용 49.68㎡(공급 19평형, 2Bay 복도식) 단일 평형 단지**
* **리모델링 평형**: 전 조합원 세대 100% **전용 59.90㎡(공급 25평형, 3Bay 계단식) 단일 평형 완벽 배정**
* **단지 규모**: 기존 지하 1층~지상 21층 709세대 $\rightarrow$ **지하 4층~지상 25층 775세대 (일반분양 66세대 공급)**
* **주차 환경**: 기존 세대당 0.58대(412대) $\rightarrow$ **세대당 1.31대(1,019대, 지하 4개층 직통 EV, 100% 지상공원화)**
* **인허가 현황**: 안양시 평촌 1기 신도시 최초 용적률 완화 기준(301.49%) 적용 **건축심의 통과 완료**

## 🌟 핵심 구현 기능

1. **인터랙티브 Before & After 슬라이더**
   - 1996년 복도식 노후 단지 vs 2028년 포스맥 스틸아트월 & 커튼월룩 랜드마크 외관 비교
   - 터치 및 마우스 드래그를 지원하는 반응형 분할 화면 비교기
2. **혁신 신평면 & 공간 대확장 뷰어 (전용 59㎡ 특화)**
   - 기존 2Bay 소형 복도식 구조에서 3Bay 계단식 맞통풍 판상형 구조로 탈바꿈
   - `59㎡ A타입 (3Bay 판상형 시그니처)`, `59㎡ B타입 (와이드 거실 특화형)`, `기존 49㎡ 복도식 평면 비교` 동적 SVG 도면 렌더링
3. **클럽 더샵(Club The Sharp) 하이엔드 커뮤니티 투어**
   - 피트니스 & GX, 스크린 실내 골프연습장, 호텔식 사우나, 작은도서관 & 오픈 스터디카페, 게스트하우스, 키즈라운지
4. **평촌 입지 & 생활 인프라 인터랙티브 맵**
   - 지하철 4호선 평촌역(도보 4분), 평촌 중앙공원(도보 3분), 명문 평촌 학원가, 한림대 성심병원 등 카테고리별 필터링
5. **사업 추진 현황 & 일정 로드맵**
   - 조합설립인가 $\rightarrow$ 포스코이앤씨 시공사 선정 $\rightarrow$ 안전진단 통과 $\rightarrow$ **안양시 건축심의 통과(평촌 최초 용적률 301.49% 완화 적용)** $\rightarrow$ 연내 사업계획승인 신청 진행 중
6. **스마트 59㎡ 가치 상승 시뮬레이터**
   - 초원세경 709세대 전 세대 100% 전용 59.90㎡ 배정에 맞춘 특화 옵션 시뮬레이션
   - 평면 타입(59A 판상형 / 59B 와이드형), 발코니 확장(+21.5㎡), 배정 층수(로얄층 / 중저층) 선택에 따른 실사용 면적(81.4㎡) 및 66세대 일반분양 수익 절감 효과 산출
7. **포스코이앤씨 공식 조감도 & 단지 실사 갤러리 및 라이트박스**
   - 포스코이앤씨 건축심의 통과 공식 조감도(1280x904), 단지 마스터플랜 조감도, 1996년 초원세경 현장 실사(KB부동산 정본)
   - 클릭 시 고해상도 전체화면 라이트박스 및 상세 스펙 안내 뷰어 제공

## 🚀 실행 방법

### 방법 1. 웹 브라우저에서 바로 열기
`index.html` 파일을 더블 클릭하거나 크롬, 엣지, 웨일 등 원하는 웹 브라우저로 드래그하여 즉시 확인하실 수 있습니다.

### 방법 2. 로컬 웹 서버 실행 (권장)
현재 백그라운드 서버가 구동 중이며, 필요 시 아래 명령어로 수동 구동할 수 있습니다:

```bash
python -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속
